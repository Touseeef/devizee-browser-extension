# Devizee - Privacy Focused (Universal Browser Extension)

Official browser extension for **Devizee Lite** and **Devizee Pro** desktop applications.

---

## 🔒 Privacy & Architecture Guarantees
- **100% Local**: Zero telemetry, zero analytics, zero external network requests.
- **Local Loopback Only**: Relays links strictly to `127.0.0.1` (`42421` for Devizee Lite, `42422` for Devizee Pro), Native Messaging (`com.devizee.native_host`), or safe protocol handlers (`streamgrab://` / `devizee://`).
- **No Cookie Exfiltration**: Follows strict security standards (SEC-9) — session authentication is performed locally on your device by the desktop application.

---

## 🚀 Features
1. **Universal Dual-Tier Support**: Auto-detects whether Devizee Lite or Devizee Pro is running.
2. **One-Click Media Grab**: Auto-detects videos & music on YouTube, TikTok, Instagram, Twitter/X, Reddit, Facebook, Vimeo, SoundCloud, Twitch, Bilibili, and more.
3. **Floating Video Grabber**: Sleek, non-intrusive on-page button on media players (can be toggled in extension popup).
4. **Context Menu Integration**: Right-click any link, video, audio, or web page to "Download with Devizee".
5. **Optional Download Interception**: Catch large browser downloads and accelerate them with Devizee (disabled by default for user privacy).

---

## 📦 How to Install (Chromium: Chrome, Brave, Edge, Opera, Vivaldi)
1. Open your browser and navigate to the extensions page:
   - Chrome / Brave: `chrome://extensions`
   - Edge: `edge://extensions`
2. Enable **Developer mode** (toggle in the top-right corner).
3. Click **Load unpacked**.
4. Select this directory: `c:\Users\Anon\Documents\PROJECTS\devizee-extension`.
5. The **Devizee** icon will appear in your browser toolbar!
